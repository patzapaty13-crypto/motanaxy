Why MOTANAXY

Every advantage and capability, all in one place

01

Byte-Level Processing

Works with raw bytes (0-255) instead of word tokens. No tokenizer needed, handles any language or encoding natively.

02

Weight Tying

Token embedding shared with output head reduces parameters by ~30% with no loss in quality. Same weights, dual purpose.

03

Causal Masking

Pre-registered causal mask computed once at init and reused every forward pass. No future token leakage, verified by self-check.

04

Gradient Accumulation

Train with large effective batch sizes on limited memory. 4x accumulation = 4x effective batch without 4x memory.

05

Mixed Precision (AMP)

Automatic FP16 on GPU for 2x speed and 50% less VRAM. Falls back to FP32 on CPU seamlessly.

06

Cosine LR with Warmup

Linear warmup prevents early instability, cosine decay finds better optima. Configurable warmup steps and min LR ratio.

07

Auto Best Checkpoint

Monitors validation loss and automatically saves the best model. Never lose your best weights to overfitting.

08

MarkItDown Universal Reader

PDF, DOCX, PPTX, XLSX, images, audio, HTML, CSV, JSON, XML, ZIP - all converted to clean markdown for training.

09

Lazy MarkItDown Loading

MarkItDown only imported when a non-plaintext file is encountered. Zero overhead for pure code projects.

10

Content Hash Dedup

SHA-256 hash per document prevents training on identical content. Saves compute, prevents memorization bias.

11

Quality Filtering

Skips files that are too small, too large, comment-only, or binary. Only meaningful code reaches the model.

12

Train/Val/Test Splits

Document-level splitting prevents data leakage. Proper evaluation gives honest loss metrics.

13

Top-K Sampling

Generation with temperature control and top-k filtering for high-quality, diverse outputs.

14

Resume Training

Save and resume training from any checkpoint. Interrupted training doesn't mean lost progress.

15

5 CLI Commands

ingest, train, generate, info, check - complete workflow from raw data to generated code in 5 commands.

16

CPU & GPU Support

Auto-detects CUDA/MPS/CPU. Train anywhere from a laptop to a data center without code changes.

Ponytail Decision Ladder

Before writing any code, stop at the first rung that solves the problem

Does this need to exist?
YAGNI - You Ain't Gonna Need It
Does it already exist in the codebase?
Reuse existing helpers and patterns
Does the standard library do it?
pathlib, hashlib, json before any external lib
Does a native platform feature cover it?
Use built-in capabilities first
Does an installed dependency solve it?
torch, markitdown - already in requirements
Can it be one line?
One-liner configs, one-liner checks
Only then: write the minimum that works
Every line earns its place

Quick Start

Get started with MOTANAXY in 3 commands

Step 1: Ingest Data

# Collect all code files into a training corpus python -m motanaxy ingest --sources ./src ./docs --out corpus.txt

Step 2: Train Model

# Train with micro preset for 1500 steps python -m motanaxy train --corpus corpus.txt --preset micro --steps 1500

Step 3: Generate Code

# Generate code from your trained model python -m motanaxy generate --checkpoint runs/mtn/best_model.pt --prompt "def sort_list("
